# 🚀 Username Converter Application 

A Flask web application that converts usernames from URL query parameters to UPPERCASE with additional creative features!

## Features

- Converts username from query parameter to UPPERCASE
- Beautiful, modern UI with gradient design
- Displays username statistics (length, word count, etc.)


### 1) 🔁 Username Transformations
- Original username
- Uppercase
- Lowercase
- Reversed
- Alternate Case (aBcDeF)

### 2) 📊 Username Statistics
- Name Length (all characters)
- Letter count (only A–Z)
- Word count
- Vowel count
- Consonant count
- Contains numbers (Yes/No)
