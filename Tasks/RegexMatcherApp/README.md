# 📌 Regex Matcher Application 
- **Cloned version of regex101**

A  Flask-based web application that clones the **core functionality** of regex101.com i.e. given a test string and a regex, display all the matches.

✅ Enter a **Test String** and a **Regex Pattern**  
✅ Click **Submit** to display all matches  
✅ Shows **match count + matched text + start & end index**  
✅ Supports 2 important flags:  
- **IGNORECASE (i)**  
- **MULTILINE (m)**
